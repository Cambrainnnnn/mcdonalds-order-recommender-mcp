# Catalog interpretation

Query the live server catalog for names, specifications and IDs. Historical observations are not authoritative.

The current recommendation mode uses maintained products and published offers only. It does not look up cities, stores, inventory, meal preparation or official prices. No city or store fields are required. Order mode is an optional filter; leaving it unset must not block recommendation.

Disabled products remain searchable and can be included in published offers. Standalone status and price eligibility are evaluated separately. A name match may have multiple specifications; resolve ambiguity with the user rather than choosing a size by default.

An empty recommendation does not establish anything about real-world store availability.
